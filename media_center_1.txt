## 已定语义

- `send_file` 仅有单一 `source`，支持 HTTP(S)、本地路径/`file://`、完整 `media:<sha256>`；没有独立 `media` 或 base64 参数。旧 plan details 的 data URI 支持描述已过时，不据此加回功能。实际发送是否转 base64 仍由发送配置决定。
- 机器人媒体在发送前导入或复用 Media Center；发送使用临时解析副本，业务和持久化数据保留稳定媒体 ID。
- 一个平台消息可对应多个有序媒体位置，同一媒体重复出现必须保留；关联保存 kind，不按媒体 ID 排序或集合化。
- 普通未唤起群消息与普通观察 Hook 不下载媒体；实际唤起或 waiting Hook continuation 消费前才物化。纯图片、纯文件消息也进入 Chat History。
- 引用优先级：本地输出索引 → Chat History 原始 segments → 平台能力兜底。机器人输出命中本地索引时不从平台重复下载。
- 回复真实当前 Session 最新 assistant 等同普通续聊，不注入引用文本或媒体；较早 assistant 保留 fork，后台保留 resume，并恢复关联媒体；其他 Session 进入真实引用上下文。
- 恢复图片进入视觉请求，Session 保存稳定 ID 和含 ID 的文本投影；普通文件保留文件 segment，不声称模型读取了不支持的内容。
